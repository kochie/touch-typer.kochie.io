6 — Motion rules

  • Library: motion (the framer-motion successor — ~6KB gzipped). CSS transitions for hover/focus states.
  • Entrance: 240ms ease-out, 8px upward translate + opacity 0→1. Triggered on first scroll-into-view, not on every viewport entry.
  • Hover: 150ms, transform/border-color/background only. No box-shadow pulse, no jiggle.
  • Hero cursor: the blinking | after the headline is the one "look at me" element. Everything else stays quiet.
  • Respect prefers-reduced-motion: all entrance/cursor animations disabled, hover transitions stay (they're functional, not decorative).
  • No: parallax, scroll-jacking, video autoplay-with-sound, Lottie.

7 — Iconography

FontAwesome Pro (already required by repo conventions). Used in four places only:

  • One glyph per hero feature (PvP, AI, Stats, Multi-layout, Code Mode) — duotone style for a touch of editorial warmth.
  • Checkmark / dash in pricing matrix rows.
  • CTA arrows (download, "see more").
  • Footer social icons (GitHub, Mastodon, etc.).

No emoji in marketing copy. Existing emoji in changelog entries can stay (those are user-tone).
